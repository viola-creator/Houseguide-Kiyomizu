# Maana Kiyomizu

Guest guide and companion journey diagram.

- Guide: https://viola-creator.github.io/Houseguide-Kiyomizu/
- Journey: https://viola-creator.github.io/Houseguide-Kiyomizu/journey/

The published guide uses `1234` as a placeholder door code. Wi-Fi credentials are shared separately and are not included in this repository.

Static HTML; no build step is needed. GitHub Pages publishes from the root of the main branch. Edit `index.html` for the guide and `journey/index.html` for the activity diagram.

- Version 1 (saved snapshot with placeholder door code): https://viola-creator.github.io/Houseguide-Kiyomizu/version1/
- Version 2 (same layout, door-code section removed): https://viola-creator.github.io/Houseguide-Kiyomizu/version2/

Keep `version1/index.html` unchanged as the saved first version. Make further version 2 changes in `version2/index.html`. The original root guide and journey link are unchanged.
